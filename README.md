# Exercise 4-1: Survey web page

Bài tập Chương 4 (Murach's Java Servlets and JSP): sửa trang khảo sát bằng HTML5 và CSS3, thêm servlet xử lý form.

## Link web
https://ch04-survey.onrender.com

## Cấu trúc source
- `src/main/webapp/index.html`: trang khảo sát (HTML5)
- `src/main/webapp/styles/survey.css`: giao diện (CSS3)
- `src/main/webapp/images/`: logo Murach
- `src/main/java/murach/survey/SurveyServlet.java`: servlet nhận dữ liệu từ form
- `Dockerfile`, `ROOT.war`: dùng để deploy lên Render
